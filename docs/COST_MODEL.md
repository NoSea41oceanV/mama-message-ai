# 1アカウント1顔の月額原価と売価試算

更新日: 2026-08-15

> 料金は2026-08-15時点の契約画面と公開情報による試算です。Tavus、ElevenLabs、OrcaRouter、OpenAIの価格・Face枠・超過条件は変更されるため、販売判断と提出公開の直前に再確認してください。

## 1. 結論

現在契約しているTavus Starterの表示内容を使う場合、1アカウントにつき本人Faceを1つ登録し、Tavus動画を月60分以内で利用する月額原価は、次のように見積もります。

- API・ホスティングの直接原価: 約4,100円
- 為替、税、小さな従量変動を含む原価予算: 約4,500円
- 売価の最低目安: 月額7,980円
- 推奨売価: 月額9,800円

推奨売価9,800円、原価予算4,500円の場合、決済手数料・サポート人件費などを引く前の粗利は5,300円、粗利率は約54%です。

## 2. 試算条件

この資料でいう「1アカウント1顔」は、サービス利用者1アカウントにつき、次の素材を1組保持する状態です。

- Tavus本人Face: 1つ
- ElevenLabs Instant Voice Clone: 1つ
- 子どもの呼び方、好きなもの、発話速度、会話履歴: 1プロフィール分

利用量は次のように仮定します。

- 為替: 1米ドル = 150円
- Tavusリアルタイム動画: 月60分以内
- 会話生成: 月100回
- 子どもの録音: 1回最大15秒、月100回
- 返答文: 1回あたりおおむね60〜100文字、実装上の上限180文字

為替と従量課金は変動するため、最終的な請求額ではなく、価格設計のための管理会計上の目安として使用します。

### 3.1 Tavus

この試算では、実際に契約した管理画面の`Starter $22/月`、`Custom Face 1枠`、`Conversational Video 60分`を優先します。

Tavusは会話ルームの作成後から利用時間を計測し、公式料金ページでは各会話に30秒の最低課金があると説明しています。短い会話を細かく開始・終了すると、実際の発話時間より消費が増える可能性があります。

一方、[Tavusの一般公開されているDeveloper料金](https://www.tavus.io/pricing)は、現在Starter `$59/月`、Custom Replica training 3件/月、Conversational Video 100分という別構成を掲載しています。既存契約、管理画面、新規契約で表示が異なるため、商用提供前にTavusへ次を確認します。

- $22プランを継続利用できる期間
- Custom Face枠が永続保有枠か、月ごとのTraining回数か
- 60分超過時の単価と、超過課金の可否
- 複数顧客のFaceを同一ワークスペースへ保持できる上位プラン

### 3.2 ElevenLabs

[ElevenLabsの公式料金](https://elevenlabs.io/pricing)では、Starterは`$5/月`、30,000クレジットで、Instant Voice Cloningを利用できます。今回使用する`eleven_multilingual_v2`は、おおむね1文字1クレジットです。

月100回、1回60〜100文字なら6,000〜10,000クレジット程度です。実装上限の180文字で100回生成しても18,000クレジットのため、他の用途がなければStarterの月額内に収まる想定です。

### 3.3 GPT-5.6 Lunaと音声認識

[OpenAIのモデル一覧](https://developers.openai.com/api/docs/models)では、GPT-5.6 Lunaは入力100万トークンあたり`$1`、出力100万トークンあたり`$6`です。1回あたり入力1,000、出力100トークンと仮定すると、100回で約`$0.16`です。実際はOrcaRouter経由の請求単価・手数料・キャッシュ条件を優先します。

音声認識は`gpt-4o-mini-transcribe`を使います。[公式モデル情報](https://developers.openai.com/api/docs/models/gpt-4o-mini-transcribe)では、音声入力100万トークンあたり`$1.25`、出力100万トークンあたり`$5`です。最大15秒を100回、合計25分としても、本構成ではTavusとElevenLabsに比べて小さいため、月10〜20円を仮置きしています。

### 3.4 ChatGPT Sites

[ChatGPT Sitesの公式ヘルプ](https://help.openai.com/en/articles/20001339-creating-and-managing-chatgpt-sites)では、公開ベータ中は契約プランごとの上限までSites利用が含まれると案内されています。この試算では、既存ChatGPT契約の共通固定費として扱い、1アカウントあたりの追加原価を0円としています。

ベータ上限や料金体系は変更される可能性があります。高トラフィック化した時点で、独立した本番ホスティングとデータベース費用を再試算します。

## 4. 売価別の粗利

管理用原価を月4,500円として計算します。

| 月額売価 | 粗利額 | 粗利率 | 判断 |
| ---: | ---: | ---: | --- |
| 6,980円 | 2,480円 | 約36% | 実証実験向け。サポート費を吸収しにくい |
| 7,980円 | 3,480円 | 約44% | 一般販売の最低目安 |
| 9,800円 | 5,300円 | 約54% | 推奨。為替・再Training・サポートの余裕を確保 |

決済手数料、返金、問い合わせ対応、監視、障害対応、利用規約・同意管理などは上表の原価に含めていません。そのため、正式販売では月額9,800円を基本とし、Tavus利用を月60分までに制限する案を推奨します。

## 5. 60分を超える場合

現在の$22プランで超過課金できるかは、契約画面またはTavusへの確認が必要です。超過単価が確定するまでは、次のいずれかにします。

1. 月60分で動画を停止し、以後は静止画とクローン音声へ自動フォールバックする
2. 追加動画時間をオプション販売する
3. 上位プランへ移行し、Face枠と動画時間を複数顧客で配賦する

本サービスの会話は、同じ返答画面でTavusセッションを再利用し、終了操作または画面離脱時に閉じます。返答ごとに新しいルームを作るよりも、30秒の最低課金が重複しにくい構成です。

## 6. 複数アカウントへ販売する際の重要事項

現在のTavus Starterは本人Faceが1枠です。この状態では、異なる人のFaceを同時に複数保持できないため、1契約のまま複数顧客へ`1アカウント1顔`を販売することはできません。

複数顧客へ販売する前に、次のどちらかが必要です。

- 顧客数に対応したCustom Face枠を持つTavus上位契約へ変更する
- 顧客ごとに独立したTavus契約・ワークスペースを用意する

顧客数を`N`、Tavusの月額を`T`、Face枠数を`F`、共通API・ホスティング費を`S`、顧客ごとの従量費を`U`とすると、1顧客あたりの原価は次で管理します。

`1顧客原価 = T ÷ min(N, F) + S ÷ N + U`

Face枠を使い切る人数で割らない限り、空き枠分も原価になります。Tavusとの商用契約が確定した時点で、この資料の$22前提を更新します。

## 7. 含めていない費用

- 決済代行手数料と返金・チャージバック
- 消費税、外貨決済手数料、為替変動
- カスタマーサポート、監視、障害対応
- 本人確認、同意記録、法務・プライバシー対応
- Faceや音声クローンの再登録作業
- Sitesベータ上限を超えた後の本番ホスティング
- 大量利用時のTavus、ElevenLabs、OrcaRouter、OpenAI超過料金

売価決定時は、API原価だけではなく、これらを含む事業全体の粗利を毎月確認します。
