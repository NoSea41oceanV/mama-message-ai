# 実装変更一覧

## 2026-08-15 大人確認チャットの視認性・音声再生

- 子どもの発話とAIのおへんじを左右・色・送信者ラベルで区別した。
- 各吹き出しに投稿時刻を表示した。
- 通常のおへんじに利用可能な音声または音声付き動画がある場合、吹き出しからタップして再生できるようにした。
- 危険・不確実発話の大人向け引き継ぎは赤い警告吹き出しにし、外部音声・動画を生成または再生しない。

## 離れた大人向け会話確認

- 子ども向け開始ボタンを入口の主操作として大きく表示し、大人確認画面への導線を画面下部の小さなボタンへ分離した。
- 内部の家庭プロフィールUUIDを入力させず、子ども側で10分有効の6桁ペアリングコードを発行する。
- 大人側はペアリングコードに加えてサーバー側の `GUARDIAN_VIEW_ACCESS_CODE` を入力し、同じプロフィールの会話だけを確認する。
- 通常会話と安全引き継ぎをチャット表示するが、会話本文は技術ログやGitへ保存しない。
- 現行MVPはサーバーメモリ保持であり、本番では正式認証・暗号化DB・試行回数制限・監査ログへ移行する。

## 1. この文書の目的

この文書は、`origin/main`から本プルリクエストまでに追加・変更した内容を、チームの開発者・レビュアーが追跡できるようにまとめたものです。

対象は次のとおりです。

- 保護者の音声クローン
- 子ども向け返答文と安全判定
- セッション内の継続会話
- 子どもごとの呼び方・好きなもの・発話速度
- 保護者らしい話し方の再現
- HeyGen、LiveAvatar、Tavusによる動画経路
- Tavus本人Faceの作成・Training・削除・再開
- 返答画面からの連続録音と固定レイアウト
- 素材の暗号化保存、同意管理、削除
- API、環境変数、依存関係、テスト、公開構成

APIキー、保護者の写真・元音声・生成メディア・暗号鍵はGitHubへ含めません。

## 2. プロダクトの利用目的

主な利用者は、母親や父親などの保護者を待って不安になった3〜6歳の子どもと、その場にいる大人です。

想定場面:

- ワンオペ中の父親との留守番
- ベビーシッターや祖父母による一時預かり
- 保育園の延長保育で迎えを待つ時間
- 就寝前や、出張・単身赴任中の保護者を待つ時間
- 入院・別居などで一時的に保護者と離れている時間

本サービスは、子どもを黙らせるための自動応答ではありません。その場の保育者・シッター・家族が寄り添う際に、本人同意済みの声と顔を使って安心できる会話を補助します。

## 3. 利用者向けの変更

### 3.1 保護者の声を使った返答

- 大人向け設定画面から、保護者の写真と音声を登録できるようにしました。
- 音声は最大2分、1〜2分を推奨しています。
- ElevenLabs Instant Voice Cloneで保護者の`voice_id`を作成します。
- 通常返答では、生成した文章をElevenLabsの日本語TTSへ渡します。
- 音声未登録の共有先では固定デモ音声を再利用せず、その都度生成した返答文をブラウザ読み上げへ渡すため、表示文と音声が一致します。
- 声だけを録り直す経路を追加しました。
- 再登録・同意停止・削除時に、古いクローン音声の削除を試みます。
- APIキーと`voice_id`はブラウザへ返しません。

### 3.2 子どもへ返す文章

- 会話生成モデルをOrcaRouter経由の`openai/gpt-5.6-luna`へ変更しました。
- 返答文は原則として、子どもが読めるひらがなだけに正規化します。
- 母親・父親などの保護者が短く自然に話す文体へ調整しました。
- 「げんきだよ。きみはどう？」のような汎用的で機械的な聞き返しを避けます。
- 「きょうひま？」などの日常会話を危険判定しないよう、通常会話と安全引き継ぎの境界を修正しました。
- 「あいたい」「さみしい」「おむかえまだ？」など、分離不安の場面では、安心・見通し・その場の大人との待ち方を短く伝えます。
- 子どもの発言を否定せず、約束できない迎え時間や保護者の現在地を断定しません。

### 3.3 安全対応

- `safetyLevel`、`supportMode`、`emotion`を構造化して返します。
- 危険、暴力、迷子、知らない人、呼吸・意識・出血などの緊急語は、通常返答や保護者動画へ流しません。
- 判定不能、空入力、重大な相談は、その場にいる大人へ引き継ぎます。
- 安全引き継ぎ時は、保護者の顔・クローン音声・通常返信を停止します。
- LLMが不正な形式や危険な返答を返した場合も、ローカル判定と中立文へフォールバックします。

### 3.4 継続会話

- 返答画面のまま「このまま おはなし」から次の音声を録音できます。
- 同一`conversationId`の直近6往復を保持し、前の話題を踏まえて返答します。
- 会話履歴のTTLは30分です。
- 「おわる」を押したときは会話履歴と動画セッションを終了します。
- 二重送信を防ぐため、`requestId`と冪等キーを維持します。

### 3.5 子どもごとの設定

- 「つばさちゃん」など、子どもの呼び方を設定できます。
- 恐竜、電車、キャラクターなど、好きなものを最大5件保存できます。
- 待っている場面や会話を続ける場面で、好きな話題を自然に使います。
- 発話速度を「とてもゆっくり」「ゆっくり」「ふつう」「はやめ」から選べます。
- ElevenLabs TTSとブラウザ読み上げの双方へ速度を反映します。

### 3.6 保護者らしい話し方

- 音声クローンだけでなく、録音時の速度・抑揚・間を残しやすいTTS設定を追加しました。
- 既定値は、安定性`0.45`、類似度`0.85`、スタイル`0.2`、話者ブースト有効です。
- ElevenLabsが失敗した場合は、登録写真とブラウザ読み上げへフォールバックします。

## 4. 動画・アバター経路

### 4.1 擬似的な写真アニメーションの廃止

- 写真全体を傾ける、ズームする、左右へ動かすだけの擬似動画を本人の身振りとして扱わないようにしました。
- 本人の口の動き・表情・身振りを生成できない場合は、静止画とクローン音声へ戻します。

### 4.2 HeyGen

- Photo Avatar / Avatar IV経路を追加しました。
- 返答音声を一時アップロードし、支援モードごとの`motion_prompt`を渡します。
- 生成動画をサーバーへ取り込んだ後、外部の一時音声と動画の削除を試みます。
- 待ち時間が長いため、現在は主経路ではなく代替プロバイダーです。

### 4.3 LiveAvatar

- LiveAvatar LITEのリアルタイムセッションを追加しました。
- サンドボックスでは公開アバターで接続確認できます。
- セッションの有効期限を監視し、残り時間が短い場合は次の返答前に更新します。
- 本人アバターは管理画面で事前作成する必要があり、APIだけでは新規作成できません。

### 4.4 Tavus

- Tavus Echoを現在の主動画経路として追加しました。
- OrcaRouterで文章を作り、ElevenLabsで音声を作り、そのPCM音声をTavusへ送ります。
- Tavusは顔、口の動き、表情、自然な身振りのリアルタイム描画を担当します。
- Dailyの非公開ルームへ短時間トークンで接続します。
- `require_auth`、最大2人、既定最長5分を設定しています。
- 接続失敗・タイムアウト・切断時は、静止画とクローン音声へ戻します。

### 4.5 Tavus本人Face

- 大人向け画面で外部送信同意を確認してから、登録写真で本人Faceを作成します。
- Tavusが写真を取得するための短時間HTTPS URLを発行します。
- `queued`、`processing`、`training`、`ready`、`failed`を保持します。
- Face Trainingが画面やローカル処理のタイムアウト後も継続するよう修正しました。
- 再読み込み後にTraining状態を再取得します。
- 再試行時に既存Faceを重複作成しないようにしました。
- 登録削除・写真差し替え時は、Tavusの本人Faceを`hard=true`で削除して枠を解放します。
- 進行中のTavus会話を終了してから、Faceとローカル記録を削除します。

### 4.6 Sites共有Faceデモ

- 一般公開デモでは、Training済みTavus Faceだけを別端末から再利用できます。
- Face登録者のElevenLabsクローン音声、元音声、`voice_id`は共有しません。
- 別端末でクローン音声を使う場合、その端末の利用者が自分の声を登録する必要があります。
- 音声未登録端末ではブラウザ読み上げへ戻し、Tavusリアルタイム動画を開始しません。
- 共有先ではFaceの作成・変更・削除をできないようにしました。
- 公開範囲、停止方法、制約は`docs/SHARED_FACE_DEMO.md`にまとめました。

## 5. 画面・操作の変更

### 5.1 返答画面

- 同じ画面で動画、字幕、再生操作、継続録音を扱います。
- 継続録音中はボタンを「おわったら おしてね」へ切り替えます。
- 音声認識後は、操作枠の中身だけを「確認・もういちど・これで送る」へ切り替えます。
- 確認欄を下へ追加しないため、画面スクロールは発生しません。
- 写真・動画、吹き出し、操作枠の位置と大きさを確認前後で維持します。
- CSS Gridで画面高を配分し、確認欄表示による写真枠の圧縮を防止します。

### 5.2 大人向け設定

- 写真、元音声、音声クローン、子どもの呼び方、好きなもの、発話速度をまとめました。
- 顔・声・外部動画処理を別々の同意項目として表示します。
- Tavus本人FaceのTraining状態と失敗理由を表示します。
- 素材削除時に、ローカル暗号化データと外部クローンを削除します。

## 6. 保存・プライバシー

- ブラウザが保持するランダムな保護者プロフィールIDでデータを分離します。
- 写真、元音声、生成動画、外部プロバイダーIDを`.data`へ保存します。
- 保存データはAES-256-GCMで暗号化します。
- 暗号鍵は`.data/sampling.key`または`SAMPLING_ENCRYPTION_KEY`から取得します。
- 別プロフィールから素材URLや音声クローンを参照できません。
- 素材URLは推測困難なアクセストークンです。
- ログには会話本文、APIキー、音声、写真を保存しません。
- 技術ログと生成メディアには24時間TTLを設定しています。
- CSP、Permissions Policy、MIME制限、本文サイズ制限、同一オリジン確認を追加・強化しました。

| `GET /api/health` | 利用中のプロバイダーと設定状態を秘密値なしで返す |

| `POST /api/sampling` | 写真・声を登録し、音声クローンを作成する |
| `POST /api/sampling/voice` | 写真を維持して声だけを差し替える |
| `POST /api/sampling/preferences` | 呼び方、好きなもの、発話速度を保存する |
| `DELETE /api/sampling` | 素材、外部クローン、本人Faceを削除する |
| `GET /api/sampling/assets/*` | 権限トークン付きの写真・音声・動画を返す |
| `POST /api/sampling/video` | 本人Faceまたは非同期動画の作成を開始する |
| `GET /api/sampling/video/{jobId}` | Training・動画生成状態を取得する |
| `GET /api/tavus/training-assets/{token}` | Tavusへ有効期限付き写真を渡す |
| `POST /api/tavus/conversation` | Tavusの非公開リアルタイム会話を作る |
| `POST /api/tavus/conversations/{id}/end` | Tavus会話を終了する |
| `POST /api/liveavatar/session-token` | LiveAvatar用の短時間セッションを作る |
| `POST /api/transcriptions` | 音声を文字起こしする |
| `POST /api/responses` | 安全判定、文章、音声、動画返答を作る |
| `GET /api/responses/{requestId}` | 非同期返答の状態・結果を取得する |
| `DELETE /api/responses/{requestId}` | 完了済み返答記録を削除する |
| `DELETE /api/conversations/{id}` | 会話履歴を終了する |
| `GET /api/logs` | 匿名化した技術ログを取得する |

## 12. 公開構成

ローカルNode.js版は`http://127.0.0.1:4173`で動作します。

検証用のSites版は、次の一般公開URLへデプロイしています。

- `https://ohenji-mama-message.fumiyaa.chatgpt.site`

Sites版では、APIキーをサーバー側の秘密設定へ保存し、写真・声・会話履歴をD1/R2へ分離して保存します。Sites固有のデプロイ用ワークスペースはローカルの`sites-app/`で管理し、本プルリクエストにはNode.js版の機能変更と共有ドキュメントを含めます。

1アカウントにつき本人Faceを1つ保持する場合の月額原価、売価別粗利、Tavusの契約表示と一般公開料金の差分は、[原価と売価試算](COST_MODEL.md)にまとめています。現在の$22 Starter・動画60分以内では、管理用原価を月約4,500円、推奨売価を月9,800円としています。複数顧客へ販売する前に、TavusのFace枠と超過単価を再確認します。

## 13. 既知の制約

- Tavus本人FaceのTrainingには数時間かかる場合があります。
- Starterプランの本人Faceは1枠のため、別人へ切り替える際は既存Faceの削除が必要です。
- Tavus・ElevenLabs・OrcaRouter・OpenAIの利用料金と上限は各サービス契約に依存します。
- 本人FaceがTraining中、外部動画が失敗、または同意がない場合は静止画と音声へ戻ります。
- 生成動画は本物の保護者とのリアルタイム通話ではありません。この説明を画面から削除しません。
- 子どもだけで使わせず、保護者・保育者・シッターなどの大人が同席します。

## 14. レビュー時の確認事項

- 通常の日常会話が過剰に安全引き継ぎされないこと
- 危険・深刻な相談が通常返答へ流れないこと
- 返答文が短く自然なひらがなであること
- 声・顔・外部送信の同意が別々に確認できること
- 素材削除でローカル保存と外部クローンが削除されること
- Tavus Training中にFaceを重複作成しないこと
- 「このまま おはなし」後も、写真枠と操作枠が変形せずスクロールしないこと
- APIキー、写真、音声、会話本文がGit差分・ログへ含まれていないこと
