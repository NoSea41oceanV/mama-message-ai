## GitHubへ置かないもの

- APIキーを含む `.env`
- 保護者ごとの写真・音声・生成動画を保存する `.data/`
- `成果物/` 以下のPowerPoint、PDF、Word資料
- 自動生成した構成図、画面キャプチャ、レンダリング確認ファイル
- 一時ファイル、ログ、ローカルキャッシュ
