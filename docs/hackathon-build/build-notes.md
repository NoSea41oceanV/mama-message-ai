## 2026-08-14: MVP実装と3シナリオ検証

- Node.js標準機能だけで動くモバイル向けWeb MVPを実装した。
- 音声録音、15秒自動停止、STT、認識文確認、待機、返答、安全引き継ぎを一本につないだ。
- OrcaRouterのOpenAI互換structured outputsアダプターを実装し、レスポンス契約、タイムアウト、HTTP失敗、JSON不正を安全側へ倒した。
- OpenAI互換STTのmultipartアダプターを実装し、生音声を保存しない契約を固定した。
- メディアのLEVEL 1〜4境界を実装し、既定デモは音声埋め込みWebMのLEVEL 2、生成失敗デモは保護者らしさのないLEVEL 4とした。
- 危険語は外部ルーター送信前のローカル安全ゲートで止め、同意不備・判定不能を含めて保護者風メディアを返さないようにした。
- 技術ログを会話本文なし、最大24時間TTLとし、経路、モデル、原価、時間、状態、フォールバックだけを保持した。
- 自動テスト30件を実行し、全件成功した。動画配信、安全分類、返答ポリシー、入力長、必須ID、セッション終了時削除、セキュリティヘッダー、同意停止・再開も回帰テストへ追加した。
- in-app Browserで390x844と1280x800を確認し、通常LEVEL 2動画、生成失敗LEVEL 4、安全ADULT_HANDOFFを完走した。コンソールエラーは0件だった。
- 記事下書き、178秒のデモ台本、3名用最終レビューチェックリスト、4枚の提出用スクリーンショットを作成した。
- OrcaRouterと外部STTのライブ疎通、実モデル、実測トークン、実測コストは、この時点では未確認とした。OrcaRouterは同日中に後述のライブ接続検証を完了した。
- 検証済み画面とMicrosoft Haruka日本語音声から、2分50.005秒、1280x720、VP8/Opusのレビュー用デモ動画を自動生成した。代表フレーム、映像・音声トラック、尺を確認した。
- 8種類のMicrosoft Haruka固定WAVをデモ保護者画像と組み合わせ、音声埋め込みWebMとして生成した。動画・音声・字幕がそろってから一括表示・再生することをブラウザで確認した。これは本人の声クローンやリアルタイム口パクではない。
- 大人向け画面にデモ素材の利用停止・再開を追加し、停止中はUIとサーバー同意ゲートの両方で生成を遮断した。

## 2026-08-14: 保護者サンプリング機能

- 大人向け画面に、保護者の顔写真と10秒までの共通フレーズ音声を登録するサンプリング導線を追加した。
- 顔・声それぞれの明示同意、写真と音声のプレビュー、素材利用停止・再開、完全削除を実装した。
- 初版ではカスタム素材をサーバーメモリ内だけに保持し、削除・置換時のゼロクリアと失効可能URLを実装した。
- 通常経路では登録写真・登録音声・同じ固定字幕をLEVEL 3で返す。安全経路ではカスタム素材を一切返さず、未登録時は従来のLEVEL 2デモ動画へ戻す。
- LEVEL 3の再生中は、Web Audioで測った音声エネルギーに応じて口元と顔全体を簡易アニメーションする。音素ベースの精密なリップシンクではなく、利用不可時はCSSの補助動作へフォールバックする。
- MIME許可リスト、ファイル署名、容量、クロスサイト更新拒否、削除・同意停止後404を含む自動テスト37件を実行し、全件成功した。
- 390x844の実ブラウザで、登録、プレビュー、LEVEL 3返答、削除、旧URL失効を確認した。

## 2026-08-14: プロフィール別の永続保存

- ブラウザ初回起動時にランダムな保護者プロフィールIDを生成し、素材・同意・返答をプロフィール単位で分離した。
- 写真・声・同意情報をAES-256-GCMで暗号化し、Git管理外の `.data/guardian-samples` へ原子的に保存する。暗号鍵は環境変数またはローカル鍵ファイルを使う。
- 同じブラウザではサーバー再起動後も素材を自動復元し、別プロフィールの同意ID・素材IDでは解決できない。
- 永続化、暗号文の平文漏えい防止、再起動復元、プロフィール間の素材利用拒否を含む自動テスト39件を実行し、全件成功した。

## 2026-08-14: OrcaRouterライブ接続検証

- OrcaRouter公式APIへの認証付きリクエストがHTTP 200を返すことを確認した。
- アプリの通常経路で `READY`、`route: generate_guardian_message`、`safetyLevel: normal`、`supportMode: encourage`、`fallbackLevel: 3` を確認した。
- 解決モデルは `qwen/qwen3.7-plus`。2回のアプリ側レイテンシは約20.5秒と約21.5秒、各回のprompt tokensは58、completion tokensは1073と1113だった。
- 10秒timeoutでは `ADULT_HANDOFF` へfail-closedすることを確認し、ライブ応答を受け取れるようtimeoutを25秒へ調整した。
- `ROUTER_PROVIDER=orcarouter` の場合だけ子どもの確認済み発話を外部へ送信し、それ以外のモードではローカル処理に限定する安全境界を追加した。
- 技術ログにAPIキーと発話本文が含まれないことを確認した。`costUsd` と `providerRoute` は `null` で、費用は未計測のため成果として断定しない。
- 外部APIを使わないテスト隔離とデモモードの外部送信禁止を含む自動テスト40件を実行し、全件成功した。
