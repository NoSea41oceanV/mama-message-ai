## はじめに

AI HACK 2026に向けて、家庭で同席する大人と一緒に使う3〜6歳向けの「AIビデオメッセージ」MVPを開発しました。子どもが声で話した内容を受け取り、その場にいない保護者が許可した写真・声などをもとに、短い返答を届ける構想です。

ただし、AIが本物の保護者としてリアルタイムに会話するサービスではありません。危険や深刻な相談をAIだけで解決するものでもありません。MVPでは「AI生成であること」「同席する大人が操作と確認を支えること」「安全上の懸念があれば保護者風の返答を止めること」を体験の前提にしました。

## 解決したい課題

3〜6歳の子どもは、うれしかったことや寂しさを言葉にできても、仕事・出張・入院などで保護者がその場にいないことがあります。一方、同席するベビーシッターや保護者などの大人が寄り添っていても、離れている保護者の存在を感じられる短いきっかけが、気持ちの切り替えを助ける場面があります。

そこで目指したのが、子どもをAIに任せるのではなく、同席する大人の関わりを補助するメッセージ体験です。主デモでは、保護者が不在の家庭でベビーシッターと過ごす子どもが「今日ブロックでおうちを作ったよ」と話します。AIの返答とベビーシッターの声かけを一つの流れにします。`Mama Movie` はこの主デモ上の例であり、対象を母親だけに限定していません。

## UX：子どもの音声と、大人の確認を一つの導線にする

画面は、長い文章を読ませず、大きな操作と短い言葉で進めます。

1. 同席する大人が、保護者素材の同意表示を確認する
2. 保護者が顔写真と30秒〜2分の本人音声を登録し、顔・声・ElevenLabsへの外部送信と本人声クローン作成にそれぞれ同意する
3. 子どもが大きなマイクボタンを押して話す
4. 録音中は波形、15秒までの経過時間、「きいているよ」を表示する
5. 音声認識結果を同席する大人が確認し、「おくる」か「もういちど」を選ぶ
6. 「おへんじをとどける準備をしているよ」という待機表示を出す
7. 登録した写真・声と同じ字幕がそろってから再生する

マイク権限がない場合や認識に失敗した場合は、短い再試行案内を表示します。文章入力は主導線ではなく、デモを止めないためのフォールバックです。

## OrcaRouterは動画生成器ではなく、構造化ルーティングの監督役

この構成でOrcaRouterに期待する役割は、動画ファイルの生成ではありません。認識済みテキストから、少なくとも次の構造化値を返し、後続処理を監督することです。

- `safetyLevel`: 通常か、大人の確認が必要か、緊急か、判定不能か
- `supportMode`: 喜びを共有する、寄り添う、励ます、同席大人へ引き継ぐ、など
- `emotion`: 喜び、寂しさ、恐れ、ニュートラル、など
- `reasonCodes`: 分岐理由
- 短い返答文、声のトーン、表情の指示

想定する処理は次の通りです。

```text
子どもの音声
  -> サーバー側STT
  -> 同席大人が認識文を確認
  -> OrcaRouterが安全度・支援方法・感情を構造化
     -> 通常: 返答メディアをLEVEL 1から順に試す
     -> 安全上の懸念・判定不能: ADULT_HANDOFF
  -> 会話本文を含まない匿名技術ログ
```

### 現在デモできるもの

- Node.js 20以降で動く、外部Nodeパッケージ不要のMVP
- 音声録音、15秒自動停止、認識文の確認・再試行
- デモSTTとデモルーターによる一連の画面遷移
- `requestId` と冪等キーによる二重生成防止
- 保護者写真・30秒〜2分音声の登録、顔・声・ElevenLabs外部送信の明示同意、APIによるInstant Voice Clone作成、暗号化Voice ID保存、クローン音声プレビュー、削除
- 登録した本人写真 + 返答文から生成した本人クローン音声 + 同じ返答字幕によるLEVEL 3返答
- LEVEL 2の事前生成WebM + 埋め込み日本語音声 + 字幕
- 安全時に保護者風の音声・画像・通常返信を止める `ADULT_HANDOFF`
- route、model、cost、latency、status、fallback levelを表示する技術ログ（会話本文は記録しない）
- 通常・サンプリング・永続化・プロフィール分離・失敗・安全・同意・外部送信境界を含む70件の自動テスト

既存デモ画面のモデル名や `$0.0000` は、ライブ接続の実測結果ではありません。ライブ検証で費用は取得できていないため、ゼロ円だったとは表現しません。

### OrcaRouterライブ接続で確認済みのもの

- OrcaRouter APIを実際に呼び出すadapter
- 外部応答のJSON Schema検証、タイムアウト、失敗時の安全側フォールバック
- 公式APIへの認証付きリクエストがHTTP 200を返すこと
- アプリ経路が `READY`、`route: generate_guardian_message`、`safetyLevel: normal`、`supportMode: encourage` まで完走すること
- 解決モデルが `qwen/qwen3.7-plus` で、2回のアプリ側レイテンシが約20.5秒と約21.5秒だったこと
- 2回ともprompt tokensは58、completion tokensは1073と1113だったこと
- 返答メディアがLEVEL 3へフォールバックして完走したこと
- 技術ログにAPIキーと発話本文が含まれないこと

最初の10秒timeoutでは外部応答を待ち切れず、通常返信を返さず `ADULT_HANDOFF` へfail-closedしました。実測に基づいてtimeoutを25秒へ調整し、上記のライブ応答を確認しました。また、`ROUTER_PROVIDER=orcarouter` の場合だけ確認済み発話を外部送信し、それ以外のモードではローカル処理に限定する安全境界を追加しています。

`costUsd` と `providerRoute` はライブ技術ログでも `null` でした。モデル、トークン、レイテンシは実測済みですが、費用は未計測です。OpenAI互換STTへの差し替えadapterは実装済みですが、外部STTのライブ疎通は今回の確認対象に含めていません。

## 失敗しても体験を止めないLEVEL 1〜4

返答メディアは、品質の高さだけでなく、安全性と再現性を優先して段階的に縮退します。

| Level | 出力 | 現在の扱い |
|---|---|---|
| LEVEL 1 | 生成動画 + 音声 + 字幕 | 将来。安定して生成できる場合だけ使用 |
| LEVEL 2 | 同意済みの事前生成WebM + 埋め込み音声 + 字幕 | 現在の通常デモ。720x900の実動画として再生 |
| LEVEL 3 | 同意済み静止画/待機動画 + 音声 + 字幕 | 登録素材がある場合は本人写真、返答文から生成した本人クローン音声、同じ返答字幕を使用。動画は別音声との同時再生で完全な口同期ではない |
| LEVEL 4 | 保護者になりきらない中立案内 | 生成失敗時や安全側へ倒す必要がある場合 |

安全上の懸念、同意不備、構造化出力の不正、判定不能では、通常返信や保護者風メディアを続けず `ADULT_HANDOFF` にします。LEVEL 4は「低品質な保護者動画」ではなく、保護者らしさを外した中立案内です。

## 安全・同意・プライバシー

幼児向けサービスでは、動くことより先に「どこで止めるか」を決める必要があります。

- 利用場所は家庭、同席する大人の操作・確認を前提にする
- 保護者が明示的に許可した顔・声・写真だけを使う
- 顔と声を別々に同意し、ブラウザごとのランダムなプロフィールIDでユーザーを分離する
- 素材はサーバー専用領域へAES-256-GCMで暗号化保存し、同じブラウザでは再起動後も復元する
- 素材URLをランダム化し、削除後は即時失効させる
- 大人向け画面で、AI生成であり本人のリアルタイム発話ではないことを明示する
- 大人向け画面からデモ素材の利用を停止・再開でき、停止中はサーバーでも生成を遮断する
- 危険・深刻な相談では、通常返信、保護者風音声、動画生成を停止する
- 危険・不確実・同意無効の経路ではElevenLabs/OpenAI音声APIとD-ID/Kling動画APIを呼ばない
- 判定不能も通常ルートに流さず、同席する信頼できる大人へ引き継ぐ
- APIキーと保護者素材をクライアントや公開リポジトリへ置かない
- `ROUTER_PROVIDER=orcarouter` の場合だけ確認済み発話を外部へ送り、デモなど他モードではローカル処理に限定する
- デモでは実在する子どもの個人情報を使わない
- 技術ログに生音声や会話本文を残さず、匿名ID、経路、モデル、原価、時間、状態に絞る

本人声は、現時点で実用可能なElevenLabs Instant Voice Cloneと、利用資格がある環境向けのOpenAI Custom Voiceを環境変数で切り替えます。ElevenLabsではアプリ内の録音からAPI経由でクローンを作成し、Voice IDをプロフィール別に暗号化保存します。OpenAI Custom Voiceの実行経路も残していますが、所定の同意録音と発行済みVoice IDが必要です。両サービスを同時には呼びません。同じ返答音声は短時間キャッシュし、失敗時はブラウザ読み上げへ戻します。

このMVPは医療・心理・緊急支援の代替ではありません。必要な場合は、同席する大人が適切な支援へつなぐ設計です。

## Codexをどう活用したか

Codexは、要件整理からMVP実装、テスト、提出資料の準備までを一貫して支援しました。具体的には、リアルタイムの「母親AI」という初期表現を、安全性を考慮した「保護者同意済み素材を使うAIメッセージ」へ整理し、OrcaRouterを判断・ルーティング役として切り分けました。

また、Node.js標準機能だけで動くサーバー、音声中心の画面、構造化契約、匿名技術ログ、フォールバック、安全分岐、自動テストを反復して実装しました。Codexの提案をそのまま採用するのではなく、人間3名が短時間レビューと、外部公開・送信の最終判断を担当する進め方にしています。

## 起動とテスト

必要なのはNode.js 20以降です。外部Nodeパッケージのインストールは不要です。

```powershell
node server.mjs
```

ブラウザで `http://127.0.0.1:4173` を開きます。マイクを使わない場合は「デモ音声で進める」を選べます。

```powershell
node --test
```

外部サービスの実接続には、`.env.example` に記載するサーバー専用環境変数が別途必要です。キーをブラウザへ渡したり、リポジトリへコミットしたりしないでください。
