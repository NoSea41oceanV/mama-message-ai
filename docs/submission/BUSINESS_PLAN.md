## 結論

- 延長保育・一時預かり向けの推奨売価は、1アカウント1顔・Tavus月60分を上限として**月額9,800円**
- 現契約表示を使った管理用原価は**約4,500円/月**、決済・人件費控除前の粗利は約5,300円、粗利率は約54%
- 主構成はOrcaRouter + GPT-5.6 Luna、ElevenLabs Instant Voice Clone、Tavus Echo
- D-IDの待機動画や発話ごとのチケット課金は、現行商品の原価・価格設計に使わない
- 最初は保護者とベビーシッターの1対1の一時預かりへ提供し、保育施設は正式認証、複数保護者同意、監査ログを整えた限定Pilotから始める

詳細な計算根拠は[1アカウント1顔の月額原価と売価試算](../COST_MODEL.md)を正本とします。

## 提供価値

### 利用者

- 延長保育や一時預かりで保護者と長く会えない3〜6歳の子ども
- その場で見守る保育士、ベビーシッター、一時預かりスタッフ
- 離れた場所にいる保護者

### 解決すること

- 子どもが声で伝えた出来事や気持ちへ、保護者らしい声・話し方・姿で短く返す
- 同席する大人が認識文を確認し、必要な支援へつなぐ
- 離れた大人が、6桁ペアリング後のチャットで会話と投稿時刻を確認し、通常返答の音声を聞く
- 危険・重大・判定不能な発話では保護者になりきらず、その場の大人へ引き継ぐ

AIは保護者本人や同席する大人の代替ではありません。子どもの気持ちを受け止めるきっかけと、大人同士の情報共有を補助します。

## 90日検証計画

### 0〜30日: ベビーシッターとの一時預かりテスト

- 保護者とベビーシッター5組で初回登録、通常2往復、安全引き継ぎ、大人確認、削除を試す
- 完走率90%以上、安全経路成功100%、重大な同意事故0件を目標にする
- 24文録音の完了率と所要時間を測る

### 31〜60日: 価格と継続利用のテスト

- 7,980円と9,800円の支払意思を確認する
- 週次利用率、月間動画時間、Tavusセッション数、サポート時間を測る
- 60分到達後の静止画＋本人声フォールバックへの受容性を確認する

### 61〜90日: 見守り者共有と施設要件の検証

- 離れた大人のチャット確認について、本人確認・再接続・コード漏えい対策を評価する
- 1施設で、複数保護者同意、権限、監査ログ、削除期限を机上・限定環境で検証する
- 施設で子どもが自由利用する運用は開始しない

## 主要KPI

- 初回登録完了率、24文録音の完了時間
- 通常会話2往復の完走率
- 危険発話の`ADULT_HANDOFF`成功率と安全経路の外部メディア呼び出し0件
- ペアリング成功率、大人確認チャット閲覧率、音声再生率
- 本人声・話し方・映像の満足度
- 1契約あたり月間Tavus利用分数とセッション数
- 1契約あたりAPI原価、サポート時間、翌月継続意向
- 同意撤回・素材削除の完了時間

## 主なリスクと対策

| リスク | 対策 |
| --- | --- |
| 子どもがAIを保護者本人と誤認する | AI生成表示、同席大人の説明、本人がリアルタイムで話している表現を禁止 |
| 危険発話を通常処理する | ローカル安全判定、構造化出力検証、不確実時も大人へ引き継ぎ、外部生成0回 |
| 顔・声・会話の同意や漏えい | 用途別同意、サーバー側暗号化、削除、短時間コード、本番の正式認証と監査 |
| 24文録音の離脱 | 1文ずつの短い録音、全体進捗、再録音、途中状態の扱いをユーザーテスト |
| Tavusの価格・Face枠・最低課金 | 月60分上限、同一セッション再利用、月次原価監視、契約条件の書面確認 |
| API障害 | 静止画＋本人声、さらにブラウザ読み上げへ段階的にフォールバック |
| 施設運用の複雑さ | 1対1の一時預かり版と分離し、複数同意・権限・監査を備えた限定Pilotから開始 |
