## 撮影時の分岐

- Tavus本人Faceが利用できる場合: 本人同意済みFaceで通常2往復を撮影する
- Tavus公開テストFaceのみの場合: 「接続確認用Face」と画面・ナレーションで明示する
- 外部APIを使えない場合: デモモードまたは静止画＋音声フォールバックでUI、安全、大人確認を撮影し、ライブ接続済みとは言わない
- マイク権限が使えない場合: 文字入力は撮影継続用フォールバックとしてのみ使う

## 編集確認

- 無言の操作場面には、画面内容に対応するナレーションを入れる
- 登録を24文すべて見せず、先頭・場面切替・結合・確認を短くつなぐ
- 通常2往復、大人確認、安全引き継ぎは削らない
- APIの待ち時間はカットしてよいが、実時間より高速だと誤認させる性能表現はしない
- 実装済み、設定済み、ライブ確認済みを区別する
