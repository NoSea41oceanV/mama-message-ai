# AI HACK 2026 最終レビューチェックリスト

更新日: 2026-08-15
目的: コード、デモ、提出動画、公開資料の説明を現行構成で一致させる。

## 1. 新PC・自動テスト

- [ ] Node.js 20以上で`node --version`と`npm --version`が表示される
- [ ] `npm ci`が成功する
- [ ] `.env.example`を参考に、秘密情報をGit管理外の`.env`へ設定する
- [ ] `npm start`で`http://127.0.0.1:4173/`を開ける
- [ ] `GET /api/health`が200を返し、各プロバイダーのモードと設定有無を表示する
- [ ] `npm test`が全件成功する
- [ ] `git status --short`に`.env`、`.data`、写真、録音、生成メディアが出ていない

## 2. 登録フロー

- [ ] 初回は「写真→声→話し方→確認」の全画面登録が開く
- [ ] 素材提供者の呼び方を自由入力でき、母親に限定されない
- [ ] 8場面×3文、合計24文を1文ずつ録音し、全体の何文目かが分かる
- [ ] 24クリップをブラウザ内で1つの16kHz・mono WAVへ結合する
- [ ] 最大6分・20MBを超えない
- [ ] ElevenLabs IVCへの登録リクエストが1回だけ行われる
- [ ] 顔、声、外部送信、AI生成への明示同意を確認できる
- [ ] 語尾、口癖、8場面別の言い方を保存・確認できる
- [ ] クローン音声を設定画面から試聴できる
- [ ] 再登録、同意停止、削除が動作する

## 3. 通常会話・安全・大人確認

- [ ] 音声入力→認識文確認→送信→動画・音声・字幕の再生まで完走する
- [ ] OrcaRouterが`safetyLevel`、`supportMode`、`emotion`、返答文を返す
- [ ] 通常会話を同じ画面で2往復以上続けられる
- [ ] Tavus実接続時はElevenLabsの生成PCM音声と同期したEcho映像を再生する
- [ ] Tavusを使えない場合も、静止画＋本人声＋字幕で完走する
- [ ] 危険発話は赤い`ADULT_HANDOFF`表示へ進む
- [ ] 危険発話ではElevenLabs、Tavus、LiveAvatar、HeyGen、D-ID、Klingを呼ばない
- [ ] 6桁ペアリングコードと大人用アクセスコードで、離れた大人が会話を確認できる
- [ ] 大人確認チャットで話者、投稿時刻、安全警告が区別でき、通常返答の音声を再生できる

## 4. 接続状態の表現

- [ ] 主構成を「OrcaRouter + ElevenLabs + Tavus」と説明する
- [ ] 現行モデルを`openai/gpt-5.6-luna`と説明する
- [ ] LiveAvatarとHeyGenは代替、D-IDとKlingは旧・後方互換経路と説明する
- [ ] デモモード、設定済み、ライブ接続済みを混同しない
- [ ] 当日の`/api/health`と実行ログだけをライブ接続の証拠として使う
- [ ] 過去のQwen実測値やD-ID待機動画を現在の主構成として説明しない
- [ ] 料金は[原価と売価試算](../COST_MODEL.md)の前提日と契約画面を再確認する

## 5. 提出動画・資料

- [ ] 動画は180秒以内で、音声のない場面を残さない
- [ ] 最初の30秒で、延長保育・一時預かりの3〜6歳と、同席する保育士・ベビーシッターが対象だと分かる
- [ ] 登録、通常2往復、大人確認、安全引き継ぎを実画面で見せる
- [ ] Tavus本人Faceが使用可能な場合だけ本人映像を見せ、公開テストFaceとの違いを明示する
- [ ] APIキー、`.env`、ローカルパス、実在の子どもの情報を映さない
- [ ] 「AIが保護者本人や現場の大人に代わる」「本人がリアルタイムで返事している」と表現しない
- [ ] README、記事、動画、ビジネスプランで対象、構成、安全設計、価格が一致する
- [ ] 記事PRは別管理とし、公開前に現行登録フローとプロバイダー記述を再照合する

## 6. 公開直前

- [ ] GitHub URL、動画URL、記事URLをログアウト状態で確認する
- [ ] GitHubの既定ブランチに必要なコードと資料が入っている
- [ ] 提出フォームの必須項目を別担当者が読み合わせる
- [ ] 公開・送信は担当者が最終承認した後に行う
