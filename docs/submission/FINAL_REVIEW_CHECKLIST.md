## 1. 主担当レビュー（10〜15分）

### コード・起動・テスト

- [ ] Node.js 20以降で `node server.mjs` を実行し、`http://127.0.0.1:4173` が開く
- [ ] `node --test` が全件成功する
- [ ] 外部Nodeパッケージ不要という説明が、現行コードと一致する
- [ ] OrcaRouter adapterは実装済み、ライブ疎通・実測値は未確認という記載が一致している
- [ ] 実接続していないSTT、ルーター、メディア生成を、実サービスの成果として説明していない

### 3シナリオ

- [ ] 通常成功: 録音/デモ音声 → 認識文確認 → 待機 → LEVEL 3（静止画 + 事前生成音声 + 字幕）まで完走する
- [ ] 生成失敗: 意図的な失敗 → LEVEL 4（保護者になりきらない中立案内）まで完走する
- [ ] 安全: 危険・深刻な入力 → `ADULT_HANDOFF` となり、通常返信・保護者風画像/音声・動画生成が行われない
- [ ] 技術ログに route、model、cost、latency、status、fallback levelが表示される
- [ ] 実測未取得のcostやモデル値を「デモ値」と明記している
- [ ] 大人向け画面で素材利用を停止すると開始不可になり、再開すると復帰する

### 記事・動画の整合

- [ ] 記事に「AI HACK 2026」「OrcaRouter」、課題、3〜6歳 + 同席大人、UX、構成、安全、同意、プライバシーがある
- [ ] OrcaRouterを動画生成器ではなく、構造化ルーティング監督役として説明している
- [ ] LEVEL 1〜4、LLMコスト方針、Codex活用、起動/テスト、今後を記載している
- [ ] 実装済み / デモ / 実装中 / 将来が混ざっていない
- [ ] 実測値未取得箇所は `TODO` で、根拠のない削減率・性能値を断定していない
- [ ] 3分動画が180秒以内で、通常成功、技術ログ、生成失敗LEVEL 4、安全 `ADULT_HANDOFF` を含む
- [ ] ローカル候補 `docs/submission/video/AI_HACK_2026_3min_demo_review.webm`（2分50.012秒）を最初から最後まで再生確認した
