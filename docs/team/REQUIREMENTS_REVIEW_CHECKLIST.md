# 現行要件レビュー・チェックリスト

更新日: 2026-08-15
対象: AI HACK 2026「泣きやみなさいわが子よ」現行MVP

## 1. 対象と目的

- [ ] 主利用者は、延長保育や一時預かりで保護者と長く会えず、寂しさや不安を感じている3〜6歳の子どもである
- [ ] 見守る大人は、保育士、ベビーシッター、一時預かりスタッフを想定する
- [ ] 子どもだけに判断や操作を任せるサービスではなく、同席する大人が子どもをあやし、寂しさに寄り添う関わりを補助する
- [ ] 離れた保護者本人がリアルタイムで話していると誤認させず、同意済み素材を使ったAI生成と表示する
- [ ] 母親専用ではなく、素材提供者の呼び方を「ママ」「パパ」「先生」など自由に登録できる
- [ ] 主デモは、延長保育でお迎えを待つ子どもが「ママに会いたい。お迎えまだ？」と先生へ伝える場面である

## 2. 初回登録

- [ ] 初回だけ「写真→声→話し方→確認」の登録フローを表示し、登録後は子ども向けホームから始まる
- [ ] 顔・声・各外部サービスへの送信について、素材提供者本人の明示同意を取得する
- [ ] 8場面×3文、合計24文を1文ずつ録音できる
- [ ] 録音文は「普段その子へ話す言い方」で読むよう案内される
- [ ] 24クリップをブラウザ内で16kHz・mono WAVへ結合し、ElevenLabsへの登録APIは1回だけ呼ぶ
- [ ] 全体4〜6分、最大6分・20MBの上限を画面とサーバーの両方で守る
- [ ] 語尾、口癖、8場面ごとの言い方を個別に登録・確認できる
- [ ] 写真、元音声、Voice ID、話し方プロフィールをプロフィール単位で保存・再登録・削除できる

## 3. 子どもの会話

- [ ] 主入力は音声で、大きなマイクボタンから録音開始・停止できる
- [ ] 録音中は波形、経過時間、停止操作が見える
- [ ] 認識文を同席する大人が確認してから送信できる
- [ ] 返答は動画・音声・字幕がそろってから1つの返答として再生される
- [ ] 同じ返答画面から次の録音へ進み、通常会話を2往復以上続けられる
- [ ] `conversationId`ごとに直近6往復を保持し、30分TTLと終了操作が機能する
- [ ] 二重送信を`requestId`と冪等キーで防止する

## 4. 会話判断とメディア

- [ ] OrcaRouterが返答文と`safetyLevel`、`supportMode`、`emotion`を構造化して返す
- [ ] 現行モデルはOrcaRouter経由の`openai/gpt-5.6-luna`である
- [ ] 通常返答は子ども向けの短いひらがな中心で、事実でない迎え時刻や居場所を断定しない
- [ ] 登録した語尾・口癖・場面別表現は、安全方針と事実性より下位の補助情報として使う
- [ ] ElevenLabsで返答文と一致する本人声TTSを生成できる
- [ ] Tavus Echoを主動画経路として、生成済みPCM音声から口・表情・身振りを含む映像を再生できる
- [ ] Tavusが使えない場合は、静止画＋クローン音声＋字幕へ戻り、会話を止めない
- [ ] LiveAvatar・HeyGenは代替、D-ID・Klingは後方互換の旧経路として説明する
- [ ] `GET /api/health`で「実装済み」「設定済み」「接続済み」を区別して確認する

## 5. 安全

- [ ] 危険、暴力、迷子、知らない人、呼吸・意識・出血などの入力を通常返答へ流さない
- [ ] 空入力、判定不能、LLM形式不正も安全側へ倒す
- [ ] 安全時は「子どものそばで話を聞き、必要に応じて適切な支援につないでください」と同席大人へ案内する
- [ ] 安全経路ではOrcaRouter判定後のElevenLabs、Tavus、LiveAvatar、HeyGen、D-ID、Klingを呼ばない
- [ ] 大人確認チャットでは安全引き継ぎを赤い警告吹き出しで表示する
- [ ] 医療・心理・緊急事案をAIだけで判断・解決しない

## 6. 離れた大人の確認

- [ ] 入口では子ども向け開始ボタンを主操作にし、大人確認ボタンは画面下部へ小さく分離する
- [ ] 子ども側で10分有効の6桁ペアリングコードを発行できる
- [ ] 大人側はペアリングコードと`GUARDIAN_VIEW_ACCESS_CODE`の両方で確認画面へ入る
- [ ] 子どもの発話とAIのおへんじを、左右・色・送信者ラベルで区別する
- [ ] 各吹き出しに投稿時刻が表示される
- [ ] 通常返答の音声または音声付き動画を吹き出しから再生できる
- [ ] 会話本文はGitや技術ログへ保存しない
- [ ] 現行のメモリ保持・簡易コードはデモ用であり、本番要件は正式認証、暗号化DB、試行制限、監査ログである

## 7. デモ完了条件

- [ ] `npm ci`後に`npm test`が通る
- [ ] キー不要のデモモードで起動し、音声権限拒否時も文字入力で完走できる
- [ ] 通常会話を2往復できる
- [ ] 危険発話が赤い安全引き継ぎへ進み、外部メディア生成が0回である
- [ ] 6桁コードで離れた大人のチャット確認と音声再生ができる
- [ ] 実接続デモではOrcaRouter、ElevenLabs、Tavusの状態を`/api/health`で確認する
- [ ] APIキー、`.env`、`.data`、実在人物の写真・音声、子どもの会話本文がGit差分にない
